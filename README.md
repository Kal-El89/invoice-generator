# Professional Invoice Generator / პროფესიონალური ინვოისების გენერატორი

[English]
A dynamic web application for individual and bulk invoice generation in PDF format.

## Project Structure
- **index.html** – User interface and tab-based layout.
- **style.css** – Styling, theme colors, and responsive design.
- **script.js** – Application logic, calculations, CSV processing, and integration with `html2pdf.js` and `JSZip`.

## Usage
1. Download or clone the repository.
2. Open `index.html` in any modern web browser.
3. Select your desired mode (Bulk Generation, Custom Invoice, Company Invoice, or Itemized Product Invoice).
4. Fill in the details and download your ready-to-use PDF file.

[ქართული]
ვებ-აპლიკაცია ინვოისების დინამიური და მასობრივი გენერაციისთვის (PDF ფორმატში).

## პროექტის სტრუქტურა
- **index.html** – მომხმარებლის ინტერფეისი და ტაბების სტრუქტურა.
- **style.css** – დიზაინი და ვიზუალური სტილები.
- **script.js** – ლოგიკა, გათვლები, CSV ფაილების დამუშავება და ბიბლიოთეკების ინტეგრაცია.

## გამოყენება
1. გადმოწერეთ ან დააკლონეთ პროექტი.
2. გახსენით `index.html` ფაილი ბრაუზერში.
3. აირჩიეთ სასურველი რეჟიმი (მასობრივი გენერაცია, ინდივიდუალური ინვოისი, შპს „ნეთვორქერ თიმი“ ან პროდუქციის ინვოისი).
4. შეავსეთ მონაცემები და გადმოწერეთ მზა PDF ფაილი.
